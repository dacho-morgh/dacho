# T24 backend scoring slice

`apps/backend/src/reviews/scoring.ts` exports `validateAndScoreReview(input: unknown)`. Input shape: `{ variant: 'ordinary' | 'employer', state: 'draft' | 'final', scores, answers?, calculatedScores? }`. It returns `{ valid, scores: { a, b, c, weightedHundredths }, errors }`; errors use stable dotted paths. Scores are calculated from submitted row inputs. Optional client `calculatedScores`, when present, must exactly match all four server values; they are never trusted as calculation inputs.

Score entries use the keys and contracts in `review-rubric.md`. Tier rows have `{ tier, score }`; development method uses tier keys `reverse_engineering`, `improvement`, `internationally_new`. A3 is `{ articles: boolean, domesticPatentCount: nonnegative integer, international: boolean }`; article flag adds 2, domestic patents add 3 each capped at 9, international flag adds 9. Scores use integer raw points. Weighted total is exact integer hundredths: `45*A + 40*B + 15*C`, maximum 5505 (55.05 points), with no normalization, pass mark, advancement, ranking, or reviewer aggregation.

Draft mode permits absent score rows and qualitative answers, while validating every supplied value. Final mode requires all rubric rows and variant-specific qualitative fields: ordinary's 13 yes/no answers; employer's full risk checklist (yes/no for yes/no prompts, nonblank text for open prompts); both variants require recommendation and top-five yes/no plus nonblank rationale. `no` is completed answer. Optional final answer fields are not silently scored.

This module is pure validation/calculation, not a route, persistence model, authorization check, assignment/round/version check, state transition or lock. Future workflow integration must first authorize the actor against active assignment and current form version, pass server-authoritative variant/state and answer values, persist returned calculated scores server-side, and only then perform authorized finalization/locking. It does not establish assignment/round prerequisites; T24 remains open.
